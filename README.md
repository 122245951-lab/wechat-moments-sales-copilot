# 朋友圈成交助手 · WeChat Moments Sales Copilot

> 看客户的圈，说对的话，出得了货。

把客户朋友圈从"刷着玩"变成**销售情报源与成交触点**：上传客户朋友圈截图，AI 输出一套可落地的成交武器——**客户商业画像 → 购买信号分级 → 分层触达话术 → 朋友圈海报配图**。

---

## ✨ 核心亮点

| 亮点 | 价值 |
|------|------|
| **截面 → 时序 → 信号 → 行动 四层洞察** | 不止"客户最近发了啥"，而是 4 层递进：截面快照（生活阶段/消费力/兴趣）→ 时间序列（变化趋势）→ 信号提取（购买意图）→ 行动建议（何时找、说什么） |
| **🔴 信号分级体系（核心交付）** | 每条朋友圈标注信号类型：🔴购买信号 / 🟡生活事件 / 🟠负面情绪 / ⚫流失预警，附证据与置信度 |
| **P0/P1/P2 行动矩阵 + 可直接发送话术** | 黄金 24h（P0）→ 3-7 天（P1）→ 月度跟进（P2），每条话术即复制即发，不用再想措辞 |
| **8 行业信号库** | 保险/房产/教育/美业/母婴/汽车/企业服务/泛零售，按行业校准"什么算购买信号" |
| **朋友圈海报 AI 生图工作流** | 1:1 / 9:16 配图 + 防中文翻车流程，出圈素材不用外包 |
| **HTML 客户档案卡** | 一键存档客户画像，下个月跟进还能"记得住这个客户" |
| **内置合规护栏（硬性）** | 仅限商业客户场景、不贴人格标签、结论附证据与置信度、截图不留存不转发 |

## 🚀 快速开始

1. 把本 Skill 安装到支持 Skill 机制的 AI 助手（Claude Code / WorkBuddy 等）。
2. 发送**客户朋友圈截图**（时间线页，单张即可；多张不同时间可输出时间序列分析，准确率更高）。
3. 说一句："分析这个客户的朋友圈，看看怎么跟进"。
4. 拿到画像 + 信号分级 + 分级话术；需要时再说"出一张 1:1 活动海报"。

### 三种输入形态

| 输入 | 说明 |
|------|------|
| 📸 多张时间线截图（推荐） | 不同时间截屏 → 时间序列洞察，判断"最近是否在变有钱/有需求" |
| 🖼 单张截图 | 截面快照，结果标注"单图 · 低置信度" |
| 💬 口头描述 | 无截图也可分析，但会标注"低置信度 · 基于转述" |

### 四阶段产出

1. **客户商业画像**：生活阶段、消费力、兴趣关注（7 类 26 项维度），每条附截图证据
2. **购买信号分级**：🔴/🟡/🟠/⚫ 四类信号逐条标注
3. **分级触达策略**：P0/P1/P2 行动矩阵 + 行业话术
4. **物料产出（可选）**：朋友圈海报 / 配图文案

## ⚠️ 合规声明

本工具仅用于**商业客户关系经营场景**（存在业务关系或潜在业务关系的对象），分析基于客户公开发布的朋友圈内容，结论为倾向性参考、不构成人格判定。截图仅用于本次分析，不做存储与转发。禁止用于骚扰、歧视、隐私侵犯等不当用途。
