# 朋友圈成交助手 (WeChat Moments Sales Copilot)

**看客户的圈,说对的话,出得了货。**

把客户朋友圈从"刷着玩"变成销售情报源:上传客户朋友圈截图,AI 输出**客户商业画像 → 购买信号分级 → 分层触达话术 → 朋友圈海报配图**四件套。

## 它能帮你解决什么

| 你的问题 | 它给的答案 |
|---|---|
| "这客户最近什么情况?" | 截面快照:生活阶段、消费力、兴趣关注,每条附截图证据 |
| "他是不是要买了?" | 信号提取:🔴购买信号 / 🟡生活事件 / 🟠负面情绪 / ⚫流失预警 |
| "什么时候找他、说什么?" | P0(24h)/P1(3-7天)/P2(月度)行动矩阵 + 可直接发送的微信话术 |
| "想跟进但不知道发啥" | 8 行业话术模板(保险/房产/教育/美业/母婴/汽车/企业服务/泛零售) |
| "活动海报怎么出?" | AI 生图朋友圈海报工作流(1:1 / 9:16,防中文翻车) |
| "下个月还能记住这客户吗?" | HTML 客户档案卡,一键存档、跟进回看 |

## 快速开始

1. 安装本 skill(WorkBuddy / Claude Code 等支持 skill 的 Agent)。
2. 给 AI 发送**客户朋友圈截图**(单张即可;多张不同时间的截图能输出时间序列分析,准确率更高)。
3. 说一句:"分析这个客户的朋友圈,看看怎么跟进"。
4. 拿到画像 + 信号 + 话术;需要海报时再说"顺便出一张 1:1 的活动海报"。

## 输入要求

- 微信**朋友圈时间线**截图(该客户本人多条动态),支持首页+下拉滚动页。
- 不要发:聊天界面、评论全屏页、其他社交平台截图、多用户混合信息流。
- 只有口头描述没有截图也可以分析,但结果会标注"低置信度·基于转述"。

## 目录结构

```
wechat-moments-sales-copilot/
├── SKILL.md                          ← Agent 读取的主技能定义
├── package.json                      ← 包元数据
├── references/
│   ├── workflow.md                   ← 四阶段流程细节与失败模式
│   ├── client-profile-model.md       ← 商业画像维度清单(7 类 26 项)
│   ├── signal-guide.md               ← 信号矩阵 + P0/P1/P2 行动 + 8 行业话术库
│   ├── poster-playbook.md            ← AI 生图海报规范与防翻车流程
│   └── ethics-guardrails.md          ← 合规护栏与免责声明
└── scripts/                          ← 可选轻脚本(纯 Python 标准库,零依赖)
    ├── timeline.py                   ← 多张截图时间轴整理
    └── make_profile_card.py          ← 生成 HTML 客户档案卡
```

## 脚本使用(可选,不装也不影响核心分析)

```bash
# 时间轴整理:把目录/文件清单按时间排序,输出 LLM 可直接消费的清单
python scripts/timeline.py "截图目录" --out timeline.json

# 客户档案卡:把分析结果 JSON 变成可存档的 HTML
python scripts/make_profile_card.py profile.json -o customer_profile.html
```

## 合规声明

本工具仅用于**商业客户关系经营场景**(存在业务关系或潜在业务关系的对象),所有分析基于客户公开发布的朋友圈内容,结论为倾向性参考,不构成人格判定。截图仅用于本次分析,不做存储与转发。禁止用于骚扰、歧视、隐私侵犯等不当用途。
