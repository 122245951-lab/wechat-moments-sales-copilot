# 商业画像模型:7 类 26 项维度清单

从客户朋友圈截图中提取**商业上有用的信号**,不是心理学猎奇。每个维度都回答:这对"我该怎么和他做生意"有什么意义。

## 维度清单

### 1. 基础身份线索(用于确认画像,不作判断依据)

| 项 | 观察什么 | 商业意义 |
|---|---|---|
| 1.1 家庭阶段 | 晒娃/晒婚戒/晒父母/独居生活 | 需求场景:母婴、学区、保障、养老 |
| 1.2 所在城市/区域 | 定位、地标、方言梗、本地活动 | 可触达性、线下见面可能性 |
| 1.3 职业线索 | 工牌、办公桌、行业会议、加班吐槽 | 收入结构、决策链路 |
| 1.4 年龄区间 | 内容审美、话题代际特征 | 沟通语气与渠道偏好 |

### 2. 生活方式与消费力(消费层级判断,用证据不用猜)

| 项 | 观察什么 | 商业意义 |
|---|---|---|
| 2.1 消费展示 | 晒单、探店、旅行、大件消费 | 消费力与消费偏好档位 |
| 2.2 品牌敏感度 | 是否露品牌、品牌层级 | 推荐产品的价格带 |
| 2.3 品质追求 | 讲究细节(咖啡、健身、阅读) | 沟通话术中的价值锚点 |
| 2.4 时间分配 | 加班多/自由时间多/通勤吐槽 | 最佳触达时段 |

### 3. 兴趣与关注点(建立共同话题的入口)

| 项 | 观察什么 | 商业意义 |
|---|---|---|
| 3.1 内容主题 | 转发的文章/视频类型 | 破冰话题素材 |
| 3.2 娱乐偏好 | 影视/游戏/运动/宠物 | 日常互动切入点 |
| 3.3 学习倾向 | 考证、上课、读书打卡 | 是否"研究型买家"(爱做功课) |

### 4. 表达与沟通风格(怎么说话他听得进去)

| 项 | 观察什么 | 沟通意义 |
|---|---|---|
| 4.1 表达量 | 高频发圈 vs 长期潜水 | 触达频率与方式 |
| 4.2 表达风格 | 外放(晒情绪晒日常)vs 克制(只转干货/风景) | 私聊尺度、推销话术密度 |
| 4.3 决策倾向 | 感性(晒体验、重感受)vs 理性(晒数据、重对比) | 卖感受 vs 卖参数 |
| 4.4 幽默感 | 玩梗、自嘲、段子 | 可不可以轻松开场 |

### 5. 互动行为(关系温度计)

| 项 | 观察什么 | 商业意义 |
|---|---|---|
| 5.1 与我方互动 | 是否赞过我、评论过我 | 现有关系基础 |
| 5.2 圈内互动强度 | 朋友评论数多不多 | 社交活跃度 |
| 5.3 求助行为 | 公开求推荐(如"求靠谱装修队") | 直接需求窗口 |

### 6. 隐性状态信号(比内容更真实的线索)

| 项 | 观察什么 | 商业意义 |
|---|---|---|
| 6.1 发圈频率变化 | 骤增/骤减 | 流失预警、状态波动 |
| 6.2 情绪基调变化 | 积极→消极 | 先关怀后谈单 |
| 6.3 内容类型迁移 | 生活晒→工作吐槽→消失 | 阶段转换信号 |
| 6.4 深夜/非正常时段发圈 | 频率异常 | 压力信号,谨慎推销 |

### 7. 购买/需求显性信号(最高优先级)

| 项 | 观察什么 | 商业意义 |
|---|---|---|
| 7.1 主动询价/求推荐 | "有没有人了解 XX" | 24h 内响应 |
| 7.2 研究对比 | 转发测评、行业对比文章 | 决策中后期,专业跟进 |
| 7.3 晒出相关痛点 | 抱怨现有方案(如"又堵了") | 替换需求切入点 |
| 7.4 生活事件前置 | 新房、新车、新生儿、新工作 | 关联需求爆发点 |

## 置信度标注规则

| 置信度 | 判定 | 处理 |
|---|---|---|
| 高 | ≥3 条独立证据指向同一结论 | 可作为行动依据 |
| 中 | 1-2 条证据或间接证据 | 作为参考,话术中留余地 |
| 低 | 推断/转述/单条动态 | 仅作假设,标注"待验证" |

## 沟通路径推导(画像→行动翻译)

不要输出"客户是 XX 型人格",只输出**沟通路径**:

- 表达克制 + 理性决策 → 少刷屏、重专业内容、发对比资料,别用"限时优惠"轰炸。
- 表达外放 + 感性决策 → 用真实体验、故事、人设内容,点赞评论刷存在感。
- 长时间不互动但发圈正常 → 私聊价值型内容试探(如"看到你最近在关注 XX,正好有份资料")。
- 发圈骤停或清空 → 先私聊关怀(见 signal-guide 流失预警),不要发任何推销。

## 红线

- 禁止输出:人品定性、"渣男/渣女/海王"类标签、心理疾病猜测、宗教/地域/性别歧视推断、收入精确猜测(只给档位和"迹象")。
- 朋友圈不等于真实生活,所有结论限"从可见内容看",建议交叉验证。
