# 信号速查与行动矩阵 + 行业话术模板库

## 信号类型速查(阶段 ③ 提取用)

| 信号 | 类型 | 证据示例(截图里看什么) | 触发动作 | 时效 |
|---|---|---|---|---|
| 🔴 购买信号 | 主动询价 | "求推荐 XX""有没有人了解 XX" | 专业跟进,提供方案 | 24-48h |
| 🔴 购买信号 | 研究对比 | 转发测评、行业分析、对比文章 | 补专业信息,帮做决策 | 48h 内 |
| 🔴 购买信号 | 痛点暴露 | 抱怨现状("又堵了""这个月开销吓人") | 场景化切入,给解法 | 48h 内 |
| 🟡 生活事件 | 前置需求 | 晒新房/签约、新车、结婚、生子、新工作 | 24h 关怀 + 自然带需求场景 | 24h |
| 🟡 生活事件 | 兴趣迁移 | 开始健身/育儿/装修/考证 | 顺应该阶段提供价值内容 | 1 周内 |
| 🟠 负面情绪 | 工作压力 | 加班打卡、吐槽领导、深夜发圈 | 只关怀不推销 | 24h 内 |
| 🟠 负面情绪 | 健康/家庭 | 生病、失眠、家庭矛盾(隐晦) | 表达关心,提供情绪价值 | 立即 |
| ⚫ 流失预警 | 互动骤降 | 以前常互动,近期无互动 | 价值型私聊试探 | 立即 |
| ⚫ 流失预警 | 停更/清空 | 长期不更新或清空朋友圈 | 私聊关怀,勿发广告 | 立即 |

## 行动优先级矩阵

```
遇到多信号并存 → 按下表顺序处理,先处理上面的:

① ⚫ 流失预警   → 只做挽回动作,不谈单
② 🟠 负面情绪   → 关怀动作,给情绪价值,严禁夹带推销
③ 🟡 生活事件   → 关怀 + 顺势提一句相关性(非推销,是提醒)
④ 🔴 购买信号   → 正式跟进,专业方案

P0 = 24 小时内必须动作(流失/负面/强购买)
P1 = 3-7 天内动作(生活事件关联需求)
P2 = 月度节奏(无明确信号时的日常经营)
```

## 话术生成规则

1. 先给**一条主话术**(可直接复制发送),再给两条备选(稳妥型 / 轻松型)。
2. 话术必须引用客户朋友圈的真实细节(如"看到你周末去露营了"),证明你"看了他的圈",不是群发。
3. **去模板味**:行业词替换成客户语境,语气口语化,长度控制在 3 句以内(微信阅读习惯)。
4. 每条话术标注:建议发送时段与入口(私聊 / 评论先行)。

## 行业话术模板库(改写后用,禁止照搬)

### 保险

- 🔴 客户转发重疾/医疗相关文章:
  > "看到你也在关注这块,正好我最近整理了一份家庭保障配置的清单,要不要发你参考下?纯资料不推销,看完有疑问随时问我。"
- 🟡 客户晒新生儿/二宝:
  > "恭喜恭喜!当爸妈后第一件事就是想给孩子最好的。我这边有份新生儿可以办的惠民保障资料,不贵但能兜底,你需要的话我发你看看,不急。"
- 🟠 客户吐槽加班/身体累:
  > "最近看你老是加班,注意身体啊。保险这东西平时用不上,但真到累垮的时候才知道有没有区别。不催你,先好好休息。"

### 房产

- 🔴 客户问学区/区域对比:
  > "你问的这两个板块我正好都实地看过,一个适合自住一个偏投资,差别挺大。我整理过一份对比,发你看看,周六有空也可以带你实地转转。"
- 🟡 客户晒订婚/结婚:
  > "恭喜!新婚第一步基本都是看房,你们打算先看哪个区域?我这边有几个新盘首开优惠,合适的话可以先帮你们排个号,看看不吃亏。"
- 🟠 客户吐槽房东/搬家:
  > "搬来搬去确实折腾。如果考虑自己买房,现在利率是低点,月供可能比你想象中少。有空我帮你算笔账,对比下租房和供房,不买也没关系。"

### 教育(培训/课程)

- 🔴 客户晒孩子成绩/晒孩子学习问题:
  > "看到你发孩子的学习情况,正好我们最近有 X 老师的公开课,专门讲这个问题,免费试听。要不要给孩子约一个?听完不合适也没关系。"
- 🟡 客户晒孩子升学/幼升小:
  > "这个阶段家长最焦虑,我们整理了一份 X 年级衔接的规划资料,很多家长反馈有用,发你参考一下。"

### 美业(美容/医美/美发)

- 🔴 客户晒皮肤问题/素颜照自嘲:
  > "你不是皮肤差,是缺一次专业护理。看你最近状态,要不要来试一下我们新到的 XX 项目?第一次体验价很划算,不满意我请你喝奶茶。"
- 🟠 客户晒熬夜/压力大:
  > "熬夜皮肤最吃亏。我们店里周日有舒缓修复的项目,做完直接睡觉,正好适合你现在。来的时候报我名字,给你留最好的美容师。"

### 母婴/育儿

- 🟡 客户晒怀孕/产检:
  > "恭喜准妈妈!孕期要注意的还挺多,我们有个孕妈交流群,都是本地同月份的,平时交流产检经验,要拉你进来吗?"
- 🔴 客户晒宝宝用品求推荐:
  > "你问的这款我们店里有试用装,可以来领一份先试试,宝宝用着合适再买,不浪费。"

### 汽车

- 🔴 客户晒看车/试驾/对比:
  > "你试的这款我熟,它的短板在于 X,如果你在意这个,同价位 Y 可能更合适。周末我帮你约个对比试驾,两个都开开就有答案了。"
- 🟡 客户晒新车/提车(你是卖车险/车品的):
  > "恭喜提车!新车第一年保险水挺深,我帮你看看你现在这个方案有没有多花冤枉钱,纯帮忙。"

### 企业服务(财税/软件/代运营)

- 🔴 客户吐槽公司管理乱/报税烦:
  > "看你也为这些事头疼,我们最近帮几家同行解决了同样的问题,方案可以分享给你参考,不收费,合适再聊合作。"
- 🟡 客户晒公司新业务/开分店:
  > "恭喜扩张!新业务起步阶段最容易在 XX 上踩坑,我们踩过的人都懂。有份清单发你,能帮你少走弯路。"

### 泛零售/微商

- 🟡 客户晒生活日常(无需求信号):
  > "看到你最近在学烘焙?我这边有款 XX 和你这个场景挺搭,不急着买,先发你看看,觉得有用再找我。"
- ⚫ 老客户久不互动:
  > "最近没怎么见你冒泡,是太忙了还是我这边有什么让你不舒服了?有啥意见直接说,老朋友不整虚的。"

## 发送时机参考

| 场景 | 推荐时段 | 理由 |
|---|---|---|
| 私聊正事 | 工作日 10:00-11:30 / 14:30-17:00 | 工作时间注意力在线 |
| 轻松话题/破冰 | 工作日 20:00-21:30 | 刷圈高峰,回复意愿高 |
| 关怀类 | 看到对方动态后 1 小时内 | 及时性本身就是诚意 |
| 周末 | 上午 10:00-12:00 | 不打扰休息,留足阅读时间 |
| 禁止 | 23:00 后 / 对方负面情绪刚发时立即推销 | 体验灾难 |
