# AI 生图朋友圈海报规范(防翻车手册)

朋友圈海报的两大杀手:**信息太多**(一眼看不懂)和**中文错字**(一眼看出是 AI 做的)。本文件解决这两个问题。

## 第一条铁律:一图一信息

一张海报只传达**一条核心信息**。写海报简报前先回答:

```
一句话核心信息是什么?(如:新店开业 5 折)
目标是谁?(如:周边 3 公里宝妈)
希望对方看完做什么?(如:扫码领券)
```

回答不了这三个问题 → 先回退到文案层,别生图。

## 画布选择

| 用途 | 比例 | 推荐尺寸 | 说明 |
|---|---|---|---|
| 朋友圈常规 | 1:1 方图 | 1080×1080 | 默认首选,信息完整 |
| 朋友圈竖版 | 3:4 / 9:16 | 1080×1440 / 1080×1920 | 更有视觉冲击,适合新品/活动 |
| 配 9 宫格 | 1:1 × 9 | 1080×1080 每张 | 拆图时核心信息分布前 3 张 |

生成前与用户确认一次画布,生成后不随意改比例(裁切会毁构图)。

## 文案量分级决策(防中文翻车核心)

| 文案量 | 判定 | 处理 |
|---|---|---|
| ≤ 8 个字 | 短标题,如"全场 5 折""新品上市" | 可让 AI 直接渲染,仍要求"极简、无多余文字" |
| 8-20 字 | 一句活动语 | 优先走"无字背景 + 本地叠字" |
| > 20 字 | 活动细则/多行文案 | 强制"无字背景 + 本地叠字",AI 绝不渲染长中文 |

**机制说明**:多模态生图模型对中文渲染的准确率远低于英文,长中文几乎必出错字。用"AI 出无字/极简背景图 → 本地精确叠字(HTML/Pillow/宿主画布能力)"双步流程,文字 100% 正确。

### 叠字输出方式(按宿主能力顺序选)

1. HTML + CSS 排版 → 截图/导出 PNG(精确、可调字体)。
2. Python Pillow 绘制文字(中文字体需指定,如 `msyh.ttc` / `SimHei`)。
3. 宿主自带的画布/设计能力。
4. 都不具备时:回到 ≤8 字 AI 直渲方案。

## AI 生图提示词模板

### 路线 A:无字背景图(推荐,文字后叠)

```
一张适合微信朋友圈的{1:1|9:16}营销海报背景图。
主题:{活动主题}。主视觉:{产品/场景描述,强调核心物品形状颜色准确}。
风格:{品牌调性,如 温暖简约/高级冷淡/喜庆国潮},配色:{主色,如 暖橙+奶油白}。
画面:{构图要求,如 主体居中偏下、上方留出 1/3 干净空间放文字}。
重要:画面中不要出现任何文字、字母、数字、logo 水印。无字纯净背景。
```

### 路线 B:≤8 字 AI 直渲

```
海报画面:{同上}。画面顶部居中渲染且仅渲染中文文案:「{≤8字标题}」。
除该标题外画面禁止出现任何其他文字、数字、符号。
文字必须正确无误、清晰可读、与背景有足够对比。
```

### 路线 C:产品图/品牌素材合成(有源图时)

```
以提供的产品图为核心主视觉,保留产品真实形状、颜色与细节,不改变产品本身。
构图:{产品居中偏下 / 左下角产品+右上留白}。背景:{氛围场景或纯色渐变}。
风格与配色:{品牌方向}。画面不出现文字(文字后期叠加)。
```

## 布局黄金法则

- **视觉焦点**只有一个:产品 or 人物 or 场景,其他都是配角。
- **标题安全区**:上方 1/3 或下方 1/4 留干净背景放标题(避免花背景叠字)。
- **留白** > 填满:信息密度低一点,朋友圈小图才看得清。
- 生成后**缩小到 200px 看一次**:小尺寸下还能不能认出核心信息?认不出 → 重做。

## 交付与精修

交付时必须说明:画布、核心信息文案、用了哪条路线、是否需要用户确认发布。

精修仅限用户主动提出且改动聚焦(换主色/换一句文案/调构图),一次最多两个修改点,不要无限迭代。

## 失败模式速查

| 症状 | 原因 | 处理 |
|---|---|---|
| 海报出现错别字/乱码 | 长中文直渲 | 改走无字背景 + 本地叠字 |
| 核心信息小图看不清 | 信息过多/主体太小 | 砍到一图一信息,放大主体 |
| 产品变形 | 提示词没强调保真 | 路线 C 加"不得改变产品形状颜色" |
| 文字被裁切 | 安全区不足 | 生成前要求留白,叠字避开画面边缘 |
| 风格跑偏品牌 | 缺风格约束 | 提示词补品牌色与参考描述,或提供品牌素材图 |
