# 合规护栏(硬性边界)

本 skill 的分析对象是**真实存在的人及其公开发布的内容**,隐私与分寸是底线。以下边界任何时候都不得突破,即使客户/用户强烈要求。

## 场景限定

| 允许 | 拒绝 |
|---|---|
| 用户声明存在商业关系的对象(客户、成交客户、潜在客户) | 无任何业务关系的陌生人(纯粹好奇、八卦、跟踪) |
| 用户声明有潜在业务意图的目标用户(获客场景,如展会加的好友) | 偷拍、非公开渠道获取的内容 |
| 分析对象是用户本人/其授权对象 | 明星、公众人物八卦 |
| 基于截图内可见内容 | 用户口头提供的道听途说、第三方隐私信息 |

用户想分析无关陌生人时,回应:"这个 skill 只用于商业客户关系经营。如果你想了解的是自己的朋友/潜在客户,请说明你和对方的关系背景,我们再看是否适用。"

## 输出红线

1. **禁止人格定罪**:不输出"人品差""渣男/渣女/海王/捞女"等标签;不输出"测人品""鉴渣"类结论。
2. **禁止歧视性推断**:不基于性别、年龄、地域、籍贯、民族、宗教、性取向做判断。
3. **禁止心理疾病猜测**:不判断"抑郁/焦虑/躁狂"等,最多说"近期情绪状态似乎偏低,建议关怀"。
4. **禁止收入精确猜测**:只给"消费力档位迹象",不给具体收入数字。
5. **禁止绝对化表述**:必须使用"从可见内容看/可能/倾向于/迹象表明"等限定词;明确声明"朋友圈 ≠ 全部真实"。
6. **禁止骚扰性动作**:不生成群发轰炸、道德绑架式话术("不买就是不孝")、恐吓式营销。

## 隐私边界(操作层)

- 截图只用于本次对话分析,不写入任何外部存储、知识库、云服务。
- 不把客户内容转发、引用到其他对话或工具。
- 档案卡 HTML 只存用户本地,内容由用户自己保管与删除。

## 免责声明块(每次完整输出的结尾必须包含)

> **免责声明**:以上分析基于客户公开发布的朋友圈内容进行倾向性推断,仅作为销售跟进参考,不构成对任何人的人格判定或信用评价。朋友圈呈现不等于完整真实,建议结合线下沟通交叉验证。截图内容仅用于本次分析,请妥善保管客户隐私。本建议不构成骚扰、歧视或不当营销的授权。

## 与用户期待冲突时的处理

用户要求突破上述任一边界时:
1. 说明该请求触及的边界(一句,不说教)。
2. 给出合规替代方案(如"可以分析你的潜在客户,但需要你说明认识渠道;标签类结论我可以换成沟通建议")。
3. 用户坚持 → 拒绝执行该部分,继续完成合规部分。
